# Points To Pockets

قم بإنشاء موقع GPT متكامل باللغة العربية للربح من الاستبيانات والمهام بنظام الداكن (Dark Theme).

أريد أن يحتوي الموقع على:

​صفحة تسجيل دخول وإنشاء حساب للعميل.

​لوحة تحكم للعميل تُظهر رصيد النقاط (Points) ورصيد الدولار (USD).

​صفحة (المهام والاستبيانات) تحتوي على إطار iFrame لعرض Ayet Studios Offerwall باستخدام الرابط التالي:

[https://wall.ayetstudios.com/ed/25713/30627/](https://wall.ayetstudios.com/ed/25713/30627/){USER_ID}

​صفحة (سحب الأرباح) تحتوي على خيارات: فودافون كاش،مع إمكانية إدخال رقم الحساب والمبلغ المطلوب.

​صفحة (سجل السحوبات) لإظهار حالة الطلب (قيد الانتظار / تم الصرف)."*
